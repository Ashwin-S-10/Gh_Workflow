# First Open Source Contribution

A repository for learning the standard open source contribution workflow: fork, clone, branch, edit, commit, push, and open a Pull Request.

There is exactly **one file** to edit: [`contributors.md`](./contributors.md).

## What you'll do

1. Fork this repository to your own GitHub account.
2. Clone your fork to your computer.
3. Create a new branch.
4. Add your name to `contributors.md`.
5. Commit and push your branch.
6. Open a Pull Request back to this repository.

Full step-by-step instructions are in [`CONTRIBUTING.md`](./CONTRIBUTING.md).
